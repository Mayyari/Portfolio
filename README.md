# Mayyari Portfolio Website

A dark, responsive personal portfolio built with HTML5, custom CSS, JavaScript, and Bootstrap 5.

## Files

- `index.html` — page structure and content
- `style.css` — custom theme, responsive layouts, project mockups, and animations
- `script.js` — theme switch, mobile navigation, reveal animations, typing effect, project filters, and contact form behavior

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Internet access is required for Bootstrap, Bootstrap Icons, and Google Fonts CDN assets.

Recommended: use VS Code with the **Live Server** extension and click **Go Live**.

## Contact form

The form validates its fields in the browser and opens the visitor's default email application using a `mailto:` link. It does not send messages directly from the website and does not require a server. For a true in-page submission, connect a backend or a form service.

## Projects
